# Arsip Dokumentasi

Dokumen di folder ini adalah catatan historis dari Phase 1–5 (interpreter
v1/v2, HambaVM v3, obfuscator Phase 4). Banyak perintah dan sintaks di
dalamnya sudah tidak berlaku sejak **v6.0.0**, ketika semua interpreter
digabung menjadi satu core di paket `hambalang/`.

Untuk dokumentasi terkini lihat [README utama](../../README.md),
[SYNTAX.md](../../SYNTAX.md), [Grammar.ebnf](../Grammar.ebnf),
[HambaLang_Spec.md](../HambaLang_Spec.md), dan [VM_Spec.md](../VM_Spec.md).
